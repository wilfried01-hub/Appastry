# Appastry

Application web de gestion de pâtisserie : coût de revient des recettes et des gâteaux, commandes clients, devis et factures, étiquettes, stock, statistiques et prix des ingrédients mis à jour depuis Open Prices (Open Food Facts).

Tout tient dans `index.html`, sans serveur : les données sont enregistrées dans le navigateur et peuvent être synchronisées entre appareils via un Gist privé (Réglages → Synchronisation).

Site : https://wilfried01-hub.github.io/appastry/
